🌿 Git בתנועה

תרגלו ענפים, commit ומיזוג על מאגר מדומה. הפקודות משנות את הגרף מיד; שום דבר לא נכתב למחשב או ל־GitHub.

נסו לפי הסדר:

אפשר ללחוץ על השלבים או להקליד פקודות משלכם למטה.

נתמכות: git status, git log, git branch NAME, git switch NAME, git commit -m MESSAGE, git merge NAME.

היסטוריית ה־commits
